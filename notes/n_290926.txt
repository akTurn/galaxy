```python
def query_process_relationships(
        query_observations,
        process_observations
):

    relationships=[]


    process_map={

        str(p.data["process"]["pid"]):
        p

        for p in process_observations

        if p.data["process"]["name"]
        and
        "postgres"
        in
        p.data["process"]["name"]

    }


    for query in query_observations:


        pid=query.data["query"].get("pid")


        process=process_map.get(
            str(pid)
        )


        if not process:
            continue


        relationships.append(
            Relationship(

            source_entity_type=
            "database_query",

            source_entity_id=
            query.entity_id,

            relationship_type=
            "executed_by",

            target_entity_type=
            "process",

            target_entity_id=
            process.entity_id,

            timestamp=query.timestamp

            )
        )


    return relationships
```

Now:

is safer.

```python
import subprocess

class QueryDependencyCollector:
```

```python
def extract_tables(plan):

    tables=[]


    if isinstance(plan,dict):

        if "Relation Name" in plan:

            tables.append(
                (
                plan["Schema"],
                plan["Relation Name"]
                )
            )


        for value in plan.values():

                extract_tables(value)

    elif isinstance(plan,list):

        for item in plan:

    return tables
```

## Step 1: Separate query identity from query execution

In database systems, these are different things.

### Query identity

Example:

```sql
SELECT * FROM expenses;
```

This is the same query every time.

Identity:

```
query_hash = abc123
```

---

### Query execution

Every time it runs:

```
execution_id = 1
execution_id = 2
execution_id = 3
```

Different execution.

So your model should become:

```
database_query
        |
        |
        +---- query_definition
        |
        +---- execution_history
```

## Step 2: Add query hash

In your collector:

```python
import hashlib
```

Create:

```python
def query_hash(sql):

    if not sql:
        return None

    normalized = sql.lower().strip()

    return hashlib.md5(
        normalized.encode()
    ).hexdigest()
```

Example:

Input:

```sql

```

Output:

```

```

# Step 4: Save query executions

Add:

```python
def save_query_history(self, observations):

    rows=[]


    for obs in observations:

        if obs.entity_type != "database_query":
            continue


        q = obs.data["query"]


        rows.append(
            (
                q["query_hash"],
                q["database"],
                q["pid"],
                q["sql"],
                q["query_start"],
                q["duration_seconds"],
                q["state"],
                obs.timestamp.isoformat()
            )
        )


    self.conn.executemany(
    """
    INSERT INTO query_history
    (
        query_hash,
        database_name,
        pid,
        sql,
        start_time,
        duration_seconds,
        state,
        timestamp
    )
    VALUES (?,?,?,?,?,?,?,?)
    """,
    rows
    )


    self.conn.commit()
```
