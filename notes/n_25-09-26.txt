# The important idea

Galaxy is not just collecting database information.

A normal monitoring tool says:

```
CPU = 80%
Database = slow
```

Galaxy builds a **cause graph**:

```
Application process
        |
        owns connection
        |
        executes slow query
        |
        locks table
        |
        blocks another query
```

That is why we are building relationships, not just collectors.

Collectors answer:

> "What exists?"

Relationships answer:

> "How are things connected?"

The graph answers:

> "Why is something happening?"

That is the complete Database Intelligence pipeline.
