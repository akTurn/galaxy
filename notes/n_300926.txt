# Your doubt

> Both have resource details but graph not showing how to link that

The answer:

**Resource values should not be relationships.**

CPU and memory are not graph edges.

They are properties of nodes.

Think like this:

```
Host Node
============
ID:
localhost

Attributes:
CPU: 95%
Memory: 80%



        hosts


Process Node
============
ID:
pid:8272

Attributes:
CPU:88%
Memory:5%
```

The relationship only connects entities.

The observations contain measurements.
