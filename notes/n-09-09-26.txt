```python
from collectors.system import SystemCollector
from collectors.process import ProcessCollector

from core.storage.sqlite_store import SQLiteStore
from core.relationships.process import process_relationships
from core.graph.process_identity_map import ProcessIdentityMap


class Orchestrator:

    def __init__(self):

        self.collectors = [
            SystemCollector(),
            ProcessCollector(),
        ]

        self.store = SQLiteStore()

    def run_once(self):

        all_observations = []

        for collector in self.collectors:

            observations = collector.collect()

            all_observations.extend(observations)

        # Build identity map from this collection cycle
        process_observations = [
            observation
            for observation in all_observations
            if observation.entity_type == "process"
        ]

        identity_map = ProcessIdentityMap(
            process_observations
        )

        all_relationships = []

        for observation in process_observations:

            relationships = process_relationships(
                observation,
                identity_map
            )

            all_relationships.extend(
                relationships
            )

        self.store.save(all_observations)

        self.store.save_relationships(
            all_relationships
        )

        return all_observations, all_relationships
```

# 3. Create `ProcessLifecycleTracker`

Create:

```text

```

Start with:

```python
class ProcessLifecycleTracker:

    def __init__(self):

        self.previous_processes = set()

    def update(self, observations):

        current_processes = {
            observation.entity_id
            for observation in observations
            if observation.entity_type == "process"
        }

        started = current_processes - self.previous_processes

        exited = self.previous_processes - current_processes

        running = current_processes & self.previous_processes

        self.previous_processes = current_processes

        return {
            "started": started,
            "running": running,
            "exited": exited,
        }
```

```text
D
```

Then:

```text
current - previous
```

gives:

```text
D
```

Therefore:

```text
D = started
```

---

# 7. Detect exited processes

This:

```python
exited = self.previous_processes - current_processes
```

means:

> Processes that existed before but don't exist now.

Example:

```text
previous:

A
B
C

current:

A
C
D
```

Then:

```text
previous - current
```

gives:

```text
B
```

So:

```text
B = exited
```

---

# 8. Detect running processes

This:

```python
running = current_processes & self.previous_processes
```

is the **intersection**.

It means:

> Processes present in both snapshots.

Example:

```text
previous:

A
B
C

current:

A
C
D
```

Intersection:

```text
A
C
```

So:

```text
A → running
C → running
```

---

# 9. Why update `previous_processes` at the end?

This is extremely important:

```python
self.previous_processes = current_processes
```

We do it **after the comparison**.

Otherwise we'd accidentally compare:

```text
current
vs
current
```

and everything would appear to be running.

The lifecycle cycle is:

```text
old state
   ↓
collect new state
   ↓
compare
   ↓
identify changes
   ↓
new state becomes old state
```

# 11A.4 — Add `save_lifecycle_events()`

Still in:

```text
core/storage/sqlite_store.py
```

add:

```python
def save_lifecycle_events(self, events):

    rows = [
        (
            event.event_type,
            event.entity_type,
            event.entity_id,
            event.timestamp.isoformat(),
        )
        for event in events
    ]

    self.conn.executemany(
        """
        INSERT INTO lifecycle_events
            (event_type, entity_type, entity_id, timestamp)
        VALUES (?, ?, ?, ?)
        """,
        rows,
    )

    self.conn.commit()
```
