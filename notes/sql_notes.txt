def current_relationships(self):

    relationships = self.all_relationships()

    latest = {}

    for relationship in relationships:

        key = (
            relationship[0],
            relationship[1],

 ## The whole process

 Imagine your database gives you:

```
id | source | type   | target | timestamp
---|--------|--------|--------|----------
1  | user 1 | friend | user 2 | 100
2  | user 1 | friend | user 3 | 200
3  | user 1 | friend | user 4 | 150
```

 Because of:

```
ORDER BY id ASC
```

 Python receives:

```
100
200
150
```

 Your second function processes them:

```
100 → save it

200 → 200 > 100 → replace it

150 → 150 > 200 → don't replace it
```

 Final result:

```
200
```

 So the most important idea is:

 > **`all_relationships()` decides the order in which rows are given to Python. `current_relationships()` then looks at those rows and explicitly compares their timestamps to find the newest one.**

 That's why the second version is safer: **it doesn't assume that the database's `id` order is the same as timestamp order.**
